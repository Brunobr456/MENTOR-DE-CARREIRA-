🧠 Como funciona?

O sistema analisa as respostas fornecidas pelo usuário utilizando JavaScript. Cada resposta adiciona pontos para diferentes áreas profissionais. Ao final, o sistema identifica o perfil com maior pontuação e apresenta algumas carreiras relacionadas.
